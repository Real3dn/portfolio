# Design System & Direction (DESIGN.md)

## Identity & Personality
- **Engineer**: Adnan Al-Qaba (Real3dn)
- **Role**: Full-Stack Web Developer & Computer Engineer
- **Character**: Focused, architectural, restrained, authentic craftsmanship. Avoids generic hype words, AI trend-stacking, and decorative clutter.

## Dials (Liveliness Standard)
- **ENERGY**: 2 (Balanced, confident, clear contrast)
- **RHYTHM**: 2 (Consistent typographic hierarchy with intentional asymmetrical breaks)
- **MOTION**: 1 (Hover states and smooth transitions only; zero perpetual loops or pulsing widgets)

## Palette (R-29: Max 2-3 core + 1 accent)
- **Neutral Substrates**:
  - Light: `#fafaf9` (Primary Background), `#ffffff` (Surface / Card), `#18181b` (Primary Text), `#52525b` (Secondary Text), `#71717a` (Muted Text), `#e4e4e7` (Subtle Border).
  - Dark: `#09090b` (Primary Background), `#141417` (Surface / Card), `#f4f4f5` (Primary Text), `#a1a1aa` (Secondary Text), `#71717a` (Muted Text), `rgba(255, 255, 255, 0.08)` (Subtle Border).
- **Core Accent**:
  - `#2563eb` (Light mode cobalt) / `#3b82f6` (Dark mode blue) - reserved strictly for active navigation, key action highlights, and verified links. Not plastered across every button, card, and background.

## Typography (R-06)
- **Primary Sans**: `Plus Jakarta Sans`, system-ui, -apple-system, sans-serif. Used for all reading text, headlines, and navigation.
- **Technical Mono**: `JetBrains Mono`, monospace. Reserved strictly for technical data, code tags, and file specifications. Not used for decorative numbers (`01.`, `02.`) or faux-terminal effects.

## Layout & Components (R-05, R-14)
- No artificial background grids or blurred radial glow orbs.
- No copy-paste repetitive 4-card grids where every card has identical weight. Flagship work receives prominent visual display.
- No dead links or fake statistics.
